# 🧹 Day 8 — NLP Text Preprocessing

## 🎯 Objective

Build a complete text preprocessing workflow to clean and normalize raw text before applying NLP techniques.

## ✅ Tasks Completed

- Tokenized text into words and sentences.
- Converted text to lowercase.
- Removed stopwords.
- Removed punctuation using Regular Expressions.
- Applied stemming using `PorterStemmer`.
- Applied lemmatization using `WordNetLemmatizer`.
- Compared stemming and lemmatization results.
- Created a complete before-and-after preprocessing workflow.

## 🔄 Preprocessing Pipeline

Raw Text  
↓  
Tokenization  
↓  
Lowercasing  
↓  
Punctuation Removal  
↓  
Stopword Removal  
↓  
Stemming / Lemmatization  
↓  
Clean Text

## 🧠 Stemming vs Lemmatization

**Stemming:** Uses rules to remove word endings and may produce incomplete words.

**Lemmatization:** Converts words into meaningful dictionary base forms.

## 💡 Key Learning

Text preprocessing reduces noise and unnecessary variation in raw text, making it more consistent for downstream NLP tasks such as classification, vectorization, and search.
