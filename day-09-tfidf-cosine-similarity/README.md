# 📊 Day 9 — TF-IDF & Cosine Similarity

## 🎯 Objective

Understand how TF-IDF measures word importance and use cosine similarity to compare text documents.

## ✅ Tasks Completed

- Created a text corpus containing multiple topics.
- Converted documents into TF-IDF vectors.
- Generated a document-term matrix.
- Calculated pairwise cosine similarity.
- Created a similarity matrix.
- Built a function to find similar sentences.
- Compared similar and unrelated concepts.
- Visualized similarity scores using a heatmap.

Text Corpus

↓  
Ranking / Visualization

## 🧠 Concepts Covered

**TF-IDF:** Measures the importance of a word within a document relative to the entire corpus.

**Cosine Similarity:** Measures how closely two vectors point in the same direction.

## 🔬 Experiment

The corpus contained three major topics:

- 🐶 Pets
- 💻 Technology
- ✈️ Travel

A heatmap was created to visualize similarity between the documents and identify groups with related topics.

## 💡 Key Learning

TF-IDF is useful for measuring lexical similarity and document relevance. However, unlike embeddings, it does not capture deeper semantic relationships such as synonyms.
