# 🔤 Day 3 — Tokenization & Bag-of-Words

## 🎯 Objective

Understand how text can be broken into smaller units and converted into numerical features for Machine Learning.

## ✅ Tasks Completed

- Learned word-level tokenization.
- Learned sentence-level tokenization.
- Removed common stopwords.
- Removed unnecessary punctuation.
- Counted word frequency using Python.
- Implemented the Bag-of-Words concept.
- Used CountVectorizer to convert text into numerical features.

## 🔄 NLP Workflow

Raw Text  
↓  
Tokenization  
↓  
Stopword Removal  
↓  
Punctuation Filtering  
↓  
Bag-of-Words  
↓  
Numerical Features

## 🧠 Concepts Covered

- **Tokenization:** Breaks text into individual words or sentences.
- **Stopword Removal:** Removes frequently occurring words with limited information.
- **Bag-of-Words:** Represents text using word frequency.
- **CountVectorizer:** Converts text documents into a matrix of word counts.

## 💡 Key Learning

Machine Learning models work with numerical data. Bag-of-Words provides a simple way to transform text into numerical features.
