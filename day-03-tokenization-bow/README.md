# 🔤 Day 3 — Tokenization & Bag-of-Words

## 🎯 Objective

Understand how human-readable text can be broken into smaller units and converted into numerical features for Machine Learning.

## ✅ Tasks Completed

- Learned word-level tokenization.
- Learned sentence-level tokenization.
- Removed common stopwords such as `the`, `is`, `and`, etc.
- Removed unnecessary punctuation.
- Counted word frequency using Python.
- Implemented the Bag-of-Words concept.
- Used `CountVectorizer` to convert text into numerical features.
