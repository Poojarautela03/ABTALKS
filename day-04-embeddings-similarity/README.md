# 🧠 Day 4 — Text Embeddings & Similarity

## 🎯 Objective

Understand how NLP models represent sentences as numerical vectors and use those vectors to measure semantic similarity.

## ✅ Tasks Completed

- Generated numerical embeddings for multiple sentences.
- Used a pre-trained Sentence Transformer model.
- Worked with the `all-MiniLM-L6-v2` model.
- Converted sentences into high-dimensional vectors.
- Compared sentence embeddings using cosine similarity.
- Tested sentences with similar and different meanings.
- Observed the difference between word matching and semantic similarity.

## 🔄 Embedding Workflow

Sentence  
↓  
Sentence Transformer  
↓  
Embedding Vector  
↓  
Cosine Similarity  
↓  
Similarity Score

## 💡 Key Learning

Embeddings represent the meaning and context of text as numerical vectors. This makes them useful for semantic search, recommendations, document similarity, and other NLP applications.

## 🛠️ Technologies Used

- Python 3
- Google Colab
- Sentence Transformers
- `all-MiniLM-L6-v2`
- Cosine Similarity
